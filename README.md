Проект, реализующий web-сайт по выбору подходящей методологии разработки ПО для конкретного проекта. 

Пользователю предлагается оценить проект по критериям, затем применяются методы MCDA, такие как AHP и TOPSIS,
определяющие подходящую методологию с учетом всех ответов пользователя.

Модель выбора методологии разработки ПО состоит из следующих компонентов: 
1. Критерии выбора,
2. Оценка критериев выбора по каждой методологии (Waterfall, RUP, Scrum, Kanban, SAFe),
3. Оценка критериев выбора по конкретному проекту, 
4. Веса критериев выбора, определенные по методу Analytical Hierarchy Process (AHP), 
5. Определение приоритетности применения методологий по отношению к конкретному проекту с использование метода TOPSIS. 
  
Алгоритм определения подходящей методологии:
1.	Оценить конкретный проект в соответствии с критериями выбора (выбирает пользователь).
2.	Заполнить матрицу оценки каждой методологии для конкретного проекта в соответствии с выставленными оценками (предзаполнено, но можно настроить).
3.	Для полученной матрицы применить метод TOPSIS с использованием весов критериев, рассчитанных по AHP (вычисляет модель).
4.	Методология с наивысшим рейтингом по TOPSIS считается наиболее подходящей  (вычисляет модель).


Сайт разработан с использованием Django.
